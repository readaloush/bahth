# Bahth بحث

Search photos by typing in Arabic, Turkish or English.

Work in progress. Step 1 measures how well existing image-text models already handle the three languages on Flickr8k ([`notebooks/01_baselines.ipynb`](notebooks/01_baselines.ipynb)); step 2 fine-tunes a text encoder to close the gap; step 3 wraps the result in a search service.

Data used, none of it redistributed here: Flickr8k (Hodosh, Young & Hockenmaier, 2013), Arabic Flickr8k captions (ElJundi et al., 2020), TasvirEt Turkish captions (Unal et al., 2016).
